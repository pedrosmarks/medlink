CONSENTIMENTO PARA TRATAMENTO DE DADOS PESSOAIS SENSÍVEIS

1. IDENTIFICAÇÃO DO CONTROLADOR

MedLink - Sistema de Gestão Médica
Responsável pelo tratamento dos seus dados pessoais conforme Lei Geral de Proteção de Dados (LGPD - Lei 13.709/2018).

2. DADOS COLETADOS

Coletamos e tratamos os seguintes dados pessoais sensíveis relacionados à saúde:

  • Dados Pessoais: Nome, CPF, data de nascimento, endereço, telefone, e-mail
  • Dados de Saúde: Tipo sanguíneo, alergias, medicamentos, histórico médico, consultas, diagnósticos, cirurgias, vacinas
  • Dados Profissionais (Médicos): CRM, especialidade médica

3. FINALIDADE DO TRATAMENTO

Seus dados serão utilizados exclusivamente para:

  • Prestação de serviços médicos e de saúde
  • Manutenção de prontuário eletrônico
  • Comunicação entre médicos e pacientes
  • Controle de acesso ao prontuário médico
  • Cumprimento de obrigações legais e regulamentares

4. BASE LEGAL

O tratamento de dados sensíveis de saúde é realizado com base no Art. 11, II, alínea 'a' da LGPD - consentimento específico e destacado do titular para finalidades específicas.

5. COMPARTILHAMENTO DE DADOS

Seus dados poderão ser compartilhados apenas com:

  • Médicos autorizados por você
  • Autoridades sanitárias quando exigido por lei
  • Prestadores de serviços técnicos (sob contrato de confidencialidade)

6. SEUS DIREITOS

Você tem direito a:

  • Confirmação da existência de tratamento
  • Acesso aos seus dados
  • Correção de dados incompletos ou inexatos
  • Anonimização, bloqueio ou eliminação de dados desnecessários
  • Portabilidade dos dados
  • Revogação do consentimento a qualquer momento

7. SEGURANÇA DOS DADOS

Implementamos medidas técnicas e organizacionais para proteger seus dados:

  • Criptografia de dados sensíveis
  • Controle de acesso por autenticação
  • Logs de auditoria
  • Backup seguro dos dados

8. RETENÇÃO DOS DADOS

Os dados serão mantidos pelo prazo necessário para as finalidades informadas e conforme exigências legais do Conselho Federal de Medicina (mínimo de 20 anos para prontuários).

9. CONTATO

Para exercer seus direitos ou esclarecer dúvidas:
E-mail: sac@medlink.com.br
